# Spellbound app icons

Created with the built-in image-generation tool. `spellbound-key.png` is the selected app icon; `spellbound-check-alternate.png` is an alternate. The app bundles `Apps/SpellboundMac/Resources/Spellbound.icns`, generated at the standard macOS 16–1024 pixel resolutions using sips and iconutil. The monochrome menu-bar symbol remains an SF Symbol for native visibility.

## Primary prompt

Create one production-ready macOS application icon for Spellbound, a spelling practice app. Square 1024x1024 canvas, transparent outside the icon. A single centered charcoal rounded-square macOS icon tile with generous consistent transparent outer margin about 8 percent. Inside it one exquisitely crafted raised dark keyboard key, containing a large lowercase mint-green 's', and a slim mint typing caret immediately to the right of the letter. Glyph and caret must remain readable at small sizes. Restrained tactile depth, beveled key edge, precise professional geometry, soft directional highlights, elegant dark gray palette and luminous but not glowing mint. Flat front-on view, no perspective rotation. No other letters, no wordmark, no background scene, no extra icons, no decorative stars, no watermarks. High-quality contemporary Mac utility icon, extremely simple silhouette. Output the icon itself, not a mockup.

## Alternate prompt

Create one alternative production-ready macOS app icon for Spellbound, a spelling-learning typing app. 1024x1024 square, transparent outside a centered rounded-square charcoal app tile occupying about 84 percent of canvas. Design: a single large mint lowercase 'a' engraved on a dark tactile keyboard key, with a small crisp mint checkmark nestled at its lower right, suggesting learning the correct spelling. Extremely clear minimal silhouette, adult professional Mac utility aesthetic, restrained polished 3D key bevels with gentle upper-left highlights, charcoal and mint palette. Flat straight-on front view. No extra lettering, no app name, no background scene, no sparks or magic wand, no watermark. Deliver actual icon artwork, not a presentation board or screenshot.

Regenerate the bundled ICNS with `./scripts/generate-app-icon.sh`.
